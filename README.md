# Зарплата МВУ

Калькулятор зарплаты менеджера вводных уроков за цикл и админка для РОП и РГ.

- Калькулятор: https://zevs2018123-cloud.github.io/mvu-calc/
- Админка: https://zevs2018123-cloud.github.io/mvu-calc/admin/
- Суфлёр вводного урока: https://zevs2018123-cloud.github.io/mvu-calc/suflyor/ (под паролем, скрипт зашифрован)

## Как устроено

- `config.json` — условия мотивации (проценты, пороги, бонусы, ставка за встречу, ОКК, грейды). Калькулятор читает их при каждом открытии.
- `engine.js` — расчёт, общий для калькулятора и админки.
- `admin/` — админка:
  - **Команда.** РОП или РГ вносит цифры своих МВУ и видит выплаты всей команды, закрывает цикл (цифры уходят в историю, кэф на следующий цикл ставится сам), копирует таблицу в Google-таблицу. Эти данные хранятся только в браузере того, кто их внёс, и в репозиторий не попадают. Для переноса на другое устройство есть «Скачать копию» и «Загрузить копию».
  - **Условия.** Меняет мотивацию для всех. Перед сохранением внизу видна таблица порогов по длине цикла. Для сохранения нужен ключ панели.

## Ключ панели для РОП и РГ

Ключ — это токен GitHub с правом менять только этот репозиторий.

1. GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token.
2. Token name: `mvu-calc admin`, Expiration: на свой выбор (например, 1 год).
3. Repository access: **Only select repositories** → `mvu-calc`.
4. Permissions → Repository permissions → **Contents: Read and write**. Больше ничего не включать.
5. Generate token, скопировать и передать РОП и РГ. Они один раз вставляют его в админке во вкладке «Условия» → «Ключ панели».

Если ключ утёк, его можно удалить на той же странице GitHub, и он перестанет работать.

После сохранения GitHub Pages обновляет сайт за 1–2 минуты.

## Как считается

- Процент берётся со всей выручки (своя + клоузеры) по ступени, до которой дошёл МВУ. Если выручка меньше первого порога, процента нет.
- Пороги, минимум встреч и бонусы заданы для базовой длины цикла (7 дней) и пересчитываются пропорционально для других длин, как в таблице мотивации.
- Бонусы за конверсию в продажу и в подачу начисляются только при выполненном минимуме встреч, оба можно получить сразу.
- Кэф грейда умножает процент с продаж. Первый грейд дают за прошлый цикл от заданного процента, каждый следующий только если уже есть предыдущий.
- Процент, бонусы и ОКК выплачиваются по итогам цикла. Деньги за встречи и твёрдый фикс выплачиваются раз в месяц.
